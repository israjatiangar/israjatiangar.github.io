# israjatiangar.github.io

My personal portfolio website.\
**[Click to visit !](https://israjatiangar.github.io/)**

## What it does

- Shows my projects by pulling some of my repos from the GitHub API
- Caches the API response in localStorage for 10 days[^1] to avoid hitting rate
  limits
- Styled with [ricss](https://github.com/israjatiangar/ricss), my own classless
  CSS framework

[^1]:
    10 days was choosen because, the changes in the github are infrequent for it
    to matter.

## Tech used

- HTML, CSS and JavaScript (_with JSDoc for type checking_)
- GitHub API for project data
- Hosted on GitHub Pages
- Icons from [Phosphor](https://phosphoricons.com/)

## Run locally

Clone the repo and open `index.html`, or serve the folder with any static
server.
