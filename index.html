More About Me

What is my coding process like?

I like to make things work first, then clean them up and improve them later.

I prefer declaring things (variables, functions, classes) before using them. I don’t want to deal with hoisting headaches.

I also love organizing my code into objects. Is that OOPs? I’m not entirely sure, I just like the structure.

I’m a big fan of #region and #endregion for custom code folding. Before that, I used to separate sections with:

======Name of Section======

What languages do I know?

For programming, I'm currently learning Lua and Go, I don't like python for its white space based syntax.
Outside of coding, I'm teaching myself Russian.

TypeScript or JSDoc?

I don’t like strictly typed languages, but I do love type checking.

I like both, though I prefer JSDoc, since it doesn’t have a compile step, even if it’s a bit verbose.
